# Douban Music Helper

用于辅助创建/填写豆瓣音乐条目的 Chrome 扩展。它可以从多个音乐来源采集专辑元数据，并自动填写到豆瓣音乐新条目页面。

## 支持的数据来源

- 网易云音乐（NetEase Cloud Music）
- Bandcamp
- Discogs
- Apple Music

## 安装

1. 下载并解压发布版 ZIP。
2. 在 Chrome 地址栏打开 `chrome://extensions/`。
3. 开启右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择解压后的插件文件夹。

## 基本使用

1. 打开受支持来源的专辑页面。
2. 点击页面左上角的 `Collect` 按钮采集信息。
3. 打开豆瓣音乐“添加条目”页面。
4. 检查自动填写的信息，并按需要补充或修改。
5. 上传封面并提交。

## 更新日志

- 豆瓣音乐条目的“专辑类型”会按采集到的曲目数自动选择：1 首为 Single、2 至 4 首为 EP、5 首及以上为 Album；未采集到曲目时保留原有类型。

- 不再默认填写碟片数为 1。

### v1.0.1

- 修正 Bandcamp 默认音乐风格与曲目标题采集。
- 改进 Bandcamp Description 的 about 与 credits 组合规则。
- Bandcamp 的 Collect 按钮在滚动页面时保持可见。
